## ০. শুরু করার আগে: আপনার ৫টি নিরাপত্তা-নিয়ম
1. **একবারে একটাই কাজ।** এক ধাপ = এক পরিবর্তন + এক যাচাই + এক "সংরক্ষণ" (git commit)।
2. **সংরক্ষণের নামে commit, পাঠানোর নামে push।** `git commit` = আপনার কম্পিউটারে বুক-করা সংস্করণ, `git push` = GitHub-এ পাঠানো → Vercel অটো লাইভ করে। commit ভুল হলে সহজ ফেরান যায়, push-এর পরেও।
3. **`dist/` ফোল্ডার ছুঁবেন না।** এটি বিল্ডের আউটপুট, নিজের থেকে তৈরি হয়।
4. **`npm install` নয়, `npm ci` ব্যবহার করুন।** (এই রিপোতে `npm install` ইনস্টল ফেল করে — `package.json`-এর esbuild vs vite-8 সংঘাত।)
5. **প্রতি ধাপের শেষে:** `npm run lint` (কোড চেক) → `npm test` (২৫টি টেস্ট) → `npm run build` → ব্রাউজারে খুলে চোখে দেখে যাচাই।

ফিরে যাওয়ার কমান্ড (ভয়ংকর নয়, নিরাপদ):
`git log --oneline -5` (শেষ ৫টি সংরক্ষণ দেখুন) → `git checkout <commit-namer>` → কিন্তু **একক ফাইল ফেরাতে:** `git checkout <commit> -- <file>`।
কোনো কিছু **`git reset --hard` / `git clean` ছাড়া** ফেরাবেন না — সেটা আপনার অন্য কাজ মুছে ফেলতে পারে।

## ২. পর্ব B — সংখ্যা বাংলা করা (সবচেয়ে বেশি চোখে পড়ে; ~১–২ ঘণ্টা)
**কী হবে:** যেসব সংখ্যা আপনি বাংলা লেখার মধ্যে ইংরেজি দেখছেন, সেগুলো বাংলা হবে।
সবচেয়ে স্পষ্ট উদাহরণ — লগইন স্ক্রিনে: `মোট শর্তাবলী: ১৪টি • প্রদর্শিত হচ্ছে: 14 টি` (এক লাইনেই ১৪ আর 14)।

**কীভাবে (একটাই পদ্ধতি, ২৫টি জায়গায়):**
1. প্রথমে একটি নতুন ফাইল `src/lib/format.ts` — এতে থাকবে ৪টি ছোট ফাংশন: `toBn(সংখ্যা)` → `১২৩`, `money(টাকা)` → `১২,৩৪,৫৬৭ টাকা`, `date(তারিখ)` → `১৯/১০/২০২৬`, `count(n)` → `৫টি`।
   (এর আগে এই একই কাজের **৩টি আলাদা লাইব্রেরি** ছিল — সেজন্যই এক অ্যাপ বাংলা, আরেকটি ইংরেজি।)
2. তারপর ফর্ম-অনুযায়ী জায়গা বদল: সুপার এডমিন প্যানেলের ৭টি KPI-কার্ড ও ৩টি টেবিল, কেন্দ্রীয় ড্যাশবোর্ডের `stat.value`, নোটিশের `3/5` কাউন্টার, app4-এর জিপিএফ নম্বর + দুই তারিখ + ২টি টোস্ট, app3-এর তারিখ-সেল।
3. **একটা গোপন বাগ যা ডেটা নষ্ট করে:** app3 সেভ করার সময় তারিহ ফিল্ডে `'২০২৬-০৯-২৩'` (বাংলা অঙ্ক) ডেটাবেজে যায়। নিয়ম: **দেখানোর জায়গায় বাংলা, জমা করার জায়গায় সবসময় ইংরেজি।** সেখানে `toEn(...)` বসবে।

**যাচাই (কোড না জেনেও):** লাইভ সাইটে `/` খুলে `Ctrl+F`-এন না চেপে, শুধু চোখে দেখুন — কোনো বাংলা বাক্যের ভেতরে 0-9 থাকলে সেটা এখনও বাকি। আমি একটা স্ক্রিপ্ট দিয়ে পুরো পেজ স্ক্যান করে "০টি লিক" রিপোর্ট দেব।

**ফেরানো:** এই পর্বের প্রতিটি ফাইল আলাদা commit — অসুন্দর লাগলে `git checkout HEAD~1 -- <ফাইল>`।

## ৩. পর্ব C — ফন্ট ও প্রিন্ট এক রকম (~১ ঘণ্টা)
**সমস্যা:** app4 ভিন্ন ফন্টে দেখায়, কারণ তার HTML-তে ৩টা ফন্ট ফ্যামিলি ডাউনলোডের লাইন **নেই**-ই। আর ৬টি জায়গায় কোডের ভেতর জোর করে `Hind Siliguri` লেখা।
**করার কাজ:**
1. `app4/index.html`-এর `<link>` লাইনটি রুট `index.html`-এর মতো ৫-ফ্যামিলি করে দিন (এক লাইনের কাজ, সবচেয়ে বড় দৃশ্যমান সুবিধা)।
2. ৪টি অ্যাপের রুট + ২টি কার্ড থেকে হার্ড-কোড `font-['Hind_Siliguri',…]` সরিয়ে `font-sans`।
3. লগইন পেজের ইংরেজি শিরোনাম `font-serif` (এখন Georgia-তে রেন্ডার হয়) → `.font-bangla-serif`।
4. প্রিন্ট: app4-এর নিজস্ব ফন্ট-তালিকা (SolaimanLipi/Nikosh) বাদ দিয়ে app1/2/3-এর `.font-bangla-serif`; `src/index.css`-এর **দুটি দ্বন্দ্বপূর্ণ `@media print`** ব্লক মিলিয়ে একটি মার্জিন।
5. রুট পেজের `lang="en"` → `lang="bn"`।

**যাচাই:** app1→app4 একটি করে নমুনা ফাইলের **প্রিন্ট প্রিভিউ** (Ctrl+P) খুলে পাশাপাশি ধরুন — ফন্ট, মার্জিন ও টাকা-লেখার ধরন এক হতে হবে। স্ক্রিনে: চার অ্যাপের শিরোনামের ফন্ট এক মনে হওয়া।

**দুটো সত্যিকারের বিপদ অডিটে ধরা পড়েছে:**
1. **অ্যাপ-মধ্যে ডেটা মুছে যাওয়া:** চার অ্যাপের সেভ-করা ফাইল **একই** IndexedDB স্টোরে (`src/lib/unlimitedStore.ts`) জমা হয় এবং প্রতি সেভে পুরো স্টোর `clear()` হয় (`:21,147`)। মানে app1-এ সেভ করলে app2/app3-এর তালিকা উঠে যেতে পারে।
2. **নকল ডেটা আসল ফাইলের সঙ্গে:** app1 লোড ও সেভ করে `SAMPLE_RECORDS` (নকল নাম, `app1/App.tsx:7,312`); app4-এর ফর্মে বিয়ানীবাজার/সিলেট/"নৃপেন্দ্র নাথ সরকার"/৩০০০০০ হার্ড-কোড (`DeathClaimForm.tsx:92-184`)।
3. **লক অন্য উপজেলায় ছড়ায়:** app1/app3-এর লক-স্টেট উপজেলা-ভিত্তিক নয় (`src/utils/storage.ts:102-107`, `app3/App.tsx:22,137`); app2/app4-এর আছে।

**ক্রম (অবশ্যই এই ক্রমে):**
1. ** ব্যাকআপ নিন** — সুপার এডমিন প্যানেলের এনক্রিপ্টেড (AES-২৫৬) ফুল ব্যাকআপ নামিয়ে আলাদা ডিভাইসে রাখুন; পাসওয়ার্ড ভুলবেন না (ভুললে ফাইল আর খুলবে না)।
2. স্টোরেজ ফিক্স: প্রতি অ্যাপের রেকর্ডে অ্যাপ-কী যোগ (`app1::id`) ও `clear()`-এর বদলে শুধু নিজের প্রিফিক্স মোছা; পুরোনো ডেটা নতুন কী-তে ম্যাপ করার একবার-মাইগ্রেশন।
3. লক/সেভ স্টেট সব অ্যাপে `readScoped`/`writeScoped` দিয়ে উপজেলা-ভিত্তিক।
4. নকল ডেটা বাদ + "নমুনা তথ্য রিলোড" লিঙ্ক বাদ (`app1/components/RecordsTable.tsx:134-142`)।
5. app4-এর "আনলিমিটেড সেইভ ফাইল" ব্যাজ বাদ (সে এই স্টোর ব্যবহারই করে না)।

**যাচাই:** একটি ব্রাউজারে app2-তে ৩টি ফাইল সেভ করুন → app1-এ একটি সেভ করুন → ফিরে গিয়ে app2-এর ৩টি ফাইল এখনো আছে দেখতে হবে। দুটি আলাদা উপজেলার সেশনে লক পরীক্ষা: এক উপজেলার লক অন্যটায় দেখাবে না।

## ৭. সময়সীমা ও প্রস্তাবিত ক্রম
| পর্ব | কাজ | সময় | ঝুঁকি | দেখার মতো বদলায়? |
|---|---|---|---|---|
| A | জংক/মরা ফাইল পরিষ্কার | ১৫ মি | খুব কম | না |
| B | সংখ্যা বাংলা + ডেটাবেজ-তারিহ বাগ | ১–২ ঘ | কম | **হ্যাঁ, সবচেয়ে বেশি** |
| C | ফন্ট + প্রিন্ট | ১ ঘ | মধ্যম (প্রিন্ট) | হ্যাঁ |
| D | হেডার/ফুটার/ব্যাক | ১–২ ঘ | মধ্যম | হ্যাঁ |
| E | বাটন/লক/সেভ আচরণ | ৩–৫ ঘ | মধ্য–উচ্চ | হ্যাঁ |
| F | স্টোরেজ + নকল ডেটা | ২ ঘ | **উচ্চ (ডেটা)** | প্রথমে না, পরে স্বস্তি |

**প্রস্তাব:** B → C → A → D → E → F → G। অর্থাৎ আগে ব্যবহারকারীর চোখে যা পড়ে তা ঠিক, পরে ভেতরের গুঁড়ো।

## ৮. শব্দকোষ (ছোট)
- **commit:** কম্পিউটারে নিরাপদ সংস্করণ সংরক্ষণ · **push:** GitHub-এ পাঠানো (Vercel নিজে থেকে লাইভ করে) · **deploy:** লাইভ সাইটে ওঠা
- **component (কম্পোনেন্ট):** স্ক্রিনের এক টুকরা বার/বাটন/টেবিল, বারবার ব্যবহারযোগ্য
- **shared (শেয়ার্ড):** এক ফাইল, সব অ্যাপ ব্যবহার করে — বদলালে সব জায়গায় একসঙ্গে ঠিক হয়
- **localStorage / IndexedDB:** ব্রাউজারের নিজস্ব জমা-জায়গা (ফাইল খুলে আবার দেখার জন্য); **Supabase:** সার্ভারের ডেটাবেজ
- **RLS/RPC:** সার্ভারে অনুমতি-চেক ও ফাংশন-কল (নিরাপত্তার জন্য এগুলো অপরিবর্তিত রাখব)

## ৯. আমি কী কী করব, কী কী আপনার হাতে
- **আমি (আপনার "শুরু করুন" পেলে):** প্রতিটি পর্ব আলাদা commit করে, lint+test+build+স্ক্রিনশট যাচাইসহ push করব; প্রতি পর্বের পর সংক্ষিপ্ত বাংলা প্রতিবেদন দেব।
- **আপনি:** (১) পর্ব A-র নোটিশ-বোর্ড ফাইল রাখা/মোছা সিদ্ধান্ত, (২) ফোন নম্বরের অঙ্ক, (৩) পর্ব F শুরুর আগে এনক্রিপ্টেড ব্যাকআপ নামিয়ে রাখা, (৪) প্রতিটি পর্বের পর লাইভ সাইটে ৫ মিনিট ঘুরে দেখা এবং যা অসুন্দর লাগে শুধু বলে দেওয়া — কোড আপনি ছোঁবেন না।
