# docs/parked — রাখা কিন্তু চালু নয়

এই তিনটি কম্পোনেন্ট কোনো এ্যাপ থেকেই ইমপোর্ট হয় না (grep-এ হিট ০), তাই বিল্ডের বাইরে
`src/components/` এখান থেকে সরানো হয়েছে — মোছা হয়নি।

| ফাইল | কী | ফেরানোর নিয়ম |
|---|---|---|
| `GpfNoticeBoard14.tsx` | ১৪-শর্ত নোটিশ বোর্ড | `src/components/`-এ নামান; এটি `src/data/mockData.ts` থেকে `GPF_14_CONDITIONS` নিত, সেটি পর্ব A-তে মোছা হয়েছে — ফেরাতে হলে সেই ডেটা আবার তৈরি করতে হবে |
| `OfficialBulletNoticeBody.tsx` | সরকারি বিুলেটিন/শর্ত তালিকার বডি | `src/components/`-এ নামান; `../lib/format` ও `../types` পাথ ঠিক করে নিন (এখান থেকে পাথ এক ধাপ বেশি) |
| `PermanentDisclaimerSection.tsx` | স্থায়ী দাবিত্যাগ অংশ | `src/components/`-এ নামান |

নোটিশ বোর্ডের কাজ ফের শুরু করলে এগুলো ভিত্তি হিসেবে ব্যবহার করা যাবে, কিন্তু এখন এগুলোর
কোনো টাইপ-চেক বা বিল্ড হয় না — পুরোনো টাইপ/ডেটা পাথ ভেঙে যেতে পারে।
